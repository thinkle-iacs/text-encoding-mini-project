# Text Encoding Mini Project

A simple pure JavaScript library and project for encoding and decoding text using various schemes.

## Features

- **Three-column layout** with intuitive interface
- **Auto-insert buttons** for quick text insertion (Shakespeare sonnet, Lorem Ipsum, Alphabet, Numbers)
- **Multiple encoding schemes**: Base64, Hexadecimal, Binary, URL Encoding, ROT13
- **Real-time character counting** for both input and output
- **Responsive design** that works on different screen sizes

## Usage

1. Open `index.html` in a web browser
2. Use the auto-insert buttons to quickly add sample text, or type your own text in the input area
3. Select an encoding scheme from the dropdown menu
4. Click "Encode" to encode the text or "Decode" to decode it
5. View the result in the output column

## File Structure

- `index.html` - Main HTML structure with three-column layout
- `style.css` - Styling for the application
- `script.js` - JavaScript functionality for encoding/decoding operations

## Encoding Schemes

- **Base64**: Standard Base64 encoding/decoding
- **Hexadecimal**: Converts text to hexadecimal representation
- **Binary**: Converts text to binary (8-bit) representation
- **URL Encoding**: Encodes text for use in URLs
- **ROT13**: Simple letter substitution cipher

## Technologies

- Pure JavaScript (no external dependencies)
- HTML5
- CSS3 with modern layouts (Grid)
